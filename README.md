# MITRE Learning Tool

A modern web application designed to help security professionals, students, and GRC teams learn and understand MITRE ATT&CK techniques through "translated" flashcards.

## 🚀 Features

- **Random Technique Generator**: Instantly generate learning cards for various MITRE ATT&CK techniques.
- **Plain English Translations**: Complex technical techniques are broken down into easy-to-understand explanations.
- **Boardroom Ready**: Includes "Boardroom Pitches" to help translate technical risks into business impact.
- **Risk Analysis**: Detailed risk categories and descriptions for each technique.
- **Industry Impact**: See how specific techniques affect different industries like Finance, Healthcare, and Retail.
- **Smart Filtering**: Filter techniques by:
  - **Difficulty**: Beginner, Intermediate, or Advanced.
  - **Learning Path**: Blue Team, Red Team, Purple Team, or GRC Focus.
  - **MITRE Tactic**: From Reconnaissance to Impact.
- **History & Favorites**: Keep track of recently viewed techniques and save your favorites for later review.
- **Responsive Design**: Fully responsive UI for learning on the go.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (v18)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Custom CSS (Modern, Clean, and Accessible)
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm

### Local Development

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the development server**:
   ```bash
   npm run dev
   ```
4. **Build for production**:
   ```bash
   npm run build
   ```
